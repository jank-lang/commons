# jank-build-cmake
[![Clojars Project](https://img.shields.io/clojars/v/org.jank-lang.commons/jank-build-cmake.svg)]
Build script helper for building CMake packages.

## Usage
Add this project to your Leiningen `:build-dependencies` vector:

```clojure
[org.jank-lang.commons/jank-build-cmake "2026.09-2"]
```
