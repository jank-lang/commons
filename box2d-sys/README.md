# box2d-sys
[![Clojars Project](https://img.shields.io/clojars/v/org.jank-lang.commons/box2d-sys.svg)](https://releases.clojars.org/org.jank-lang.commons/box2d-sys)

Raw package for box2d.

## Usage
Add this project to your Leiningen `:dependencies` vector:

```clojure
[org.jank-lang.commons/box2d-sys "2026.08-1"]
```

## Example
You can find an example project [here](./example). You're welcome to copy this
to get started! To run the example project, use Leiningen:

```bash
cd example
lein run
```
