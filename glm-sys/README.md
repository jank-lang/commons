# glm-sys
[![Clojars Project](https://img.shields.io/clojars/v/org.jank-lang.commons/glm-sys.svg)](https://releases.clojars.org/org.jank-lang.commons/glm-sys)

Raw package for glm.

## Usage
Add this project to your Leiningen `:dependencies` vector:

```clojure
[org.jank-lang.commons/glm-sys "0.1-SNAPSHOT"]
```

## Example
You can find an example project [here](./example). You're welcome to copy this
to get started! To run the example project, use Leiningen:

```bash
cd example
lein run
```
