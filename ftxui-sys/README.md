# ftxui-sys
[![Clojars Project](https://img.shields.io/clojars/v/org.jank-lang.commons/ftxui-sys.svg)]
Raw package for FTXUI.

## Usage
Add this project to your Leiningen `:dependencies` vector:

```clojure
[org.jank-lang.commons/ftxui-sys "2026.08-2"]
```
